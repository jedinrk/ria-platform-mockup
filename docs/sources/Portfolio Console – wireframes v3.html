Security master

One tiered hierarchy for the whole firm: Asset class › Super sector › Sector › Sub-sector › Security. Themes are supporting tags.
HierarchyInstrument typeHeld firm-wide (₹ L)% of firm AUMKey attributesThemesStatus

Classify each security once; every model and portfolio follows. Attributes depend on the instrument type (coupon and rating for bonds, market cap and risk rating for equity, lock-in and commitment for AIFs, and so on). Open a security to change its place in the hierarchy, its type, themes or attributes.

Models

Firm-wide models, by risk profile and by strategy, on the same hierarchy as the Security master. Portfolios inherit these and can override targets and bands inline on their own Allocation & drift tab.

Model comparison

How deep each asset class is modelled

Targets are set down to the chosen level. Below it, portfolio pages still show what is held, but there is no target. Changing a depth splits or adds up existing targets for every model and portfolio override. It applies to every model.

Every level has a target and a tolerance band, and the children of a node always add up to it. Editing a node rescales what is under it and moves its siblings, so the level above never changes. The Tags column lists the attributes of the securities under each node. Click a tag, or use the filter, to narrow the tree to nodes holding matching securities. Edits last until you reload.
